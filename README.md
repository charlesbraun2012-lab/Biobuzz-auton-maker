BioSim



A browser based FTC auto maker that exports JAVA code.

This is already deployed at: https://charlesbraun2012-lab.github.io/Biobuzz-auton-maker/



Features:


1)Tank or strafer (mecanum) drive

2)Steps: Drive, Turn, Timed power, Wait, Shoot, plus Strafe and Move for strafers
 
3)Draw a line and the robot follows it 

4)Choose and rotate the starting position, with a legal-start check 

5)Drive under the hive (can be turned off) 

6)Calibration for speed, track width and wheel diameter

7)Motor names, ports and reversed settings

8)Java export with optional IMU turns and encoder driving

9)Dark and light themes, with autos saved in your browser



Notes:

1)The AI prompt box only works inside claude.ai. Everything else works anywhere.

2)It is a simulation, so tune the exported Java on your real robot.

3)Saved autos stay in each person's browser. Use export and import to share them.
